# 주유소 지도 실행 안내

1. 폴더의 `index.html`을 Edge 또는 Chrome에서 엽니다. 인터넷, Node.js 설치, 서버 실행 없이 사용할 수 있습니다.
2. **지역 자료 추출** 또는 **지도·가격 조회**를 선택한 뒤 주유소 표준 CSV와 판매가격 CSV를 각각 불러옵니다. `전국주유소표준데이터` 폴더의 CSV로 바로 시작할 수 있습니다.
3. 폴더를 옮길 때는 HTML, CSS, JavaScript와 지도 이미지 파일을 같은 폴더에 함께 둡니다.

## 로컬 서버로 실행

선택 사항으로 Windows에서 `start.cmd`를 실행한 뒤 `http://127.0.0.1:8787`을 열 수 있습니다. 서버 방식에는 Node.js 18 이상과 `전국주유소표준데이터/HangJeongDong_ver20261001.geojson`이 필요합니다. 다른 포트를 쓰려면 `node server.mjs 8788`을 실행합니다. 실행 창에서 `Ctrl+C`를 누르면 서버가 종료됩니다.

원본 GeoJSON을 교체한 경우 이 폴더에서 `node prepare-offline.mjs`를 실행해 직접 열기용 지도와 지역 목록을 다시 생성합니다.

## GitHub Pages

저장소의 **Settings → Pages → Source**에서 **GitHub Actions**를 선택하면 `main` 브랜치에 올린 앱을 배포합니다. **Actions → Deploy GitHub Pages**에서 수동으로도 실행할 수 있습니다. 저장소와 웹사이트에서 사용할 CSV는 방문자가 브라우저에서 직접 선택합니다. 작업 폴더의 원본 CSV는 로컬에 보관합니다.

## 데이터 확인

- 지역 자료 추출은 두 파일을 지역 기준으로 각각 필터링합니다. 결과 CSV를 지도 화면에 다시 불러올 수 있습니다.
- 지도 화면은 주소와 상호로 확인한 경우에만 주유소와 판매가격을 연결합니다. 연결되지 않은 판매가격 행 수는 지도 위에 표시합니다.
- CSV는 브라우저에서 처리합니다. 로컬 서버는 화면 파일과 행정구역 자료를 제공하며 `127.0.0.1`에서만 수신합니다.
